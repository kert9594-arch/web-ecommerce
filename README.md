# KEL 5 Marketplace Dimsum

Website statis HTML, CSS, dan JavaScript yang disiapkan untuk GitHub Pages.

## Cara memasang di GitHub Pages
1. Buat repository baru di GitHub.
2. Upload isi folder ini langsung ke root repository (pastikan `index.html` berada di root, bukan di dalam folder tambahan).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
6. Tunggu proses deployment selesai dan buka URL yang diberikan GitHub Pages.

## Catatan
- Website ini menggunakan penyimpanan browser (`localStorage`) untuk data demo. Data akun/keranjang tidak otomatis tersinkron antarperangkat atau browser.
- Alur checkout, pembayaran, dan pengiriman pada versi statis ini adalah simulasi antarmuka; jangan menganggapnya sebagai pembayaran atau pemesanan sungguhan tanpa backend.
- Foto profil yang diunggah disimpan di browser perangkat yang digunakan.
